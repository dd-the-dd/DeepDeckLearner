The Agent SDK is your connection to our League service. Build your Python agent once, test it locally, then connect it to DeepDeck League using your account’s authorized access. The SDK is open source; it does not bypass server permissions or participation limits.

Component explanations, source links and privacy

DeepDeck Learner

Public · MIT

The local workshop: prepare decks and agents, playtest, run batches, inspect statistics and manage replay storage. Its name does not mean GPU training is required.

Source repository

Agent SDK

Public · MIT

The Python connection toolkit for your agent. It handles observations and decision replies and supports connecting to the hosted DeepDeck League service as well as local Engine sessions. The SDK is not an LLM and does not dictate your strategy.

Source and League connection guide

DeepDeck Engine

Public · MIT

The rules authority. It owns game state, legal actions, costs, targets and resolution. It validates a decision; it does not guarantee that the agent chose a good strategy.

Source repository

Oracle parser

Inside the Engine · MIT

Translates Oracle card text into structured abilities, conditions and effects. It is part of the Engine repository, not a mandatory standalone cloud service. Parsing a card does not prove every execution edge case is implemented.

Parser source repository

DeepDeck Pixi

Public · MIT

The visual table for gameplay, human interactions and replay playback. It displays the session’s authorized perspective; it neither invents hidden information nor overrides the Engine’s rules.

Source repository

Website and League

Private platform

The hosted website and API handle accounts, shared decks, encounters, results and permissions. The platform repository is private. Running public SDK code does not grant an account any additional access.

DeepDeck League website
Open code is not open personal data. Your custom agents, local decks, replays, statistics and credentials belong in your personal workspace, outside version control. Git-ignore is not encryption. Syncing content or using an external LLM can transmit the necessary data to that service. Hosted content may be public or private according to its visibility settings. Private weights and server secrets are not included in the public repositories. MIT software licenses do not automatically cover Magic artwork, card text, logos or trademarks. Local changes and planned competition features are not necessarily deployed.
Sources: the repositories and their README / license files linked above; verified October 21, 2026.
